# Lamport Clocks

Repository for the development of an educational application designed to help users understand and work with Lamport logical clocks in distributed systems. The goal is to facilitate learning how events are ordered and how their causal relationships are represented without relying on a shared physical clock.

The project uses React, TypeScript, and Vite.

## Development

This repository uses Bun as its package manager. Install dependencies and start the development server with:

```sh
bun install
bun run dev
```

Other available commands:

```sh
bun run build
bun run lint
bun run preview
```
